# Partículas de batalha — FRLG

18 folhas PNG locais, 14.398 bytes, com os desenhos originais organizados pelo projeto comunitário [pret/pokefirered](https://github.com/pret/pokefirered/tree/037335f4c725d7c9aecdac87066f2002b4bd7e14/graphics/battle_anims/sprites), revisão `037335f4c725d7c9aecdac87066f2002b4bd7e14`.

Gráficos: Game Freak / Nintendo / The Pokémon Company. Não foi identificada licença aberta que conceda direitos sobre esses gráficos; a licença do código do projeto comunitário não transfere esses direitos. A atribuição registra a origem neste projeto de fã, conforme o recorte dos demais assets de Pokémon já utilizados.

`manifest.json` registra fonte exata, SHA-256 original/convertido, tamanho e quadros. `scripts/import-battle-effects.py` reproduz a extração com Python/Pillow, usando a revisão congelada ou `--source <checkout>`; rejeita fontes que mudaram de hash. Mantém a paleta embutida e os quadros da folha, convertendo apenas o índice zero em transparência RGBA. Nenhuma ROM é necessária ou distribuída.

Fire, bolhas, eletricidade, cristais, folhas, pedras, impactos e outras partículas são usadas por famílias de golpes. Tempos, trajetórias, escala, auras, cura, proteção e composição são adaptações do Pokébobo, não uma reprodução integral das animações do cartucho. Fada e golpes posteriores usam partículas existentes de FRLG como adaptação visual. Os 18 tipos têm efeitos; imagens ausentes usam formas próprias como fallback. Os timbres sonoros de golpes são síntese original do Pokébobo.
