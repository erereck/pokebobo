# Campo e captura de FireRed / LeafGreen

Gráficos de Game Freak / Nintendo / The Pokémon Company, organizados pelo projeto comunitário [pret/pokefirered](https://github.com/pret/pokefirered), revisão `037335f4c725d7c9aecdac87066f2002b4bd7e14`. Fontes, paletas, metatiles, transformações e limites em [FRLG-ASSETS](https://github.com/erereck/pokebobo/blob/main/licenses/FRLG-ASSETS.md).

Na 0.20.0, `red_fish_sheet.png` acrescenta os 12 quadros originais de pesca, 384×32, com índice zero transparente. Fonte exata e hashes em [fishing-manifest.json](fishing-manifest.json). Importador opcional: `scripts/import-fishing.py --source <referência local>`. Lançamento conserva quadros/offsets; espera/mordida/exclamação e o desenho das rotas são adaptações do Pokébobo.

O projeto comunitário não transfere direitos sobre os gráficos de Pokémon. Esta atribuição registra origem/transformações para o projeto de fã, no mesmo recorte não comercial das artes existentes; não é uma licença aberta desses gráficos.
